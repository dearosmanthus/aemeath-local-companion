# 第一轮人物视觉优化 · 2026-09-08

用户已认可声音，授权优化人物表现。本轮只改人物前端与对应离线测试，保留原角色文件和声音实现。

## 已完成

- 新增 `wallpaper/character-materials.mjs`，接回真实 PMX 的 30 组球面高光绑定，复用 7 张本地贴图。按眼睛、皮肤、头发、饰品、布料分别调校；布料增加颜色约束，避免抬亮黑色区域。
- 不再把不受支持的 `envMap/combine` 交给当前 toon 材质；向旧 loader 提供剥离这些字段的浅层副本，原始解析数据供新材质适配器使用。没有修改依赖或模型资源。
- `精细渲染` 开启材质细修；`原始效果` 使用基础材质和旧光照作对照。原始效果不是原游戏渲染的承诺。两者共享新的半身构图和表演系统。
- 调整柔和主光、补光与轮廓光，半身镜头更靠近脸和上身，保留头饰留白。全身构图继续保留脚部空间。
- 清晰档为标准 DPI 提供 1.5 倍采样，高 DPI 上限 2；总绘制像素受预算限制，省电档 120 万、清晰档 368.64 万。30/60fps 是调度目标，不是这次实测的持续 GPU 帧率保证。
- 从实际 PMX 精选 16 个顶点形变控制，增加倾听眉眼回应、思考微表情、短暂侧看与回看，眼球先于头部跟随目标。新增自主小动作遵守系统减少动态效果偏好。
- 保持实际播放音频驱动口型的路径，未更换 TTS、声音资源或语音请求。
- 高光贴图若失败会禁用对应附加层；基础漫反射或自定义 toon 若失败仍报告角色加载失败。共享同一贴图的情况按必需资源处理。
- 页面卸载时释放新增材质贴图，并处理异步载入晚于页面关闭的清理。
