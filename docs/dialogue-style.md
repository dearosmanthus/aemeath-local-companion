# 自然对话设定

2026-09-08，版本 `natural-dialogue-v1`。实现位于 `lib/character-dialogue.js`，同时供本地和用户主动选用的 API 通道使用；没有改变 API 地址、认证、历史隔离或网络规则。

风格目标：保持本机已有角色性格，以具体接话、适量自己的看法、随情绪变化的语气来增加自然感。不要依赖机械口头禅、每句反问、过量夸赞、编造共同经历或声称看见用户。告别时简短收尾；直接询问身份或能力时如实回答。

通常一到三句、25–80 个汉字，必要解释最多 100 字，简单回应更短。台词清理保留正常短回复的所有句子及自然停顿；超过 110 个字符才优先按完整句或分句截断。原来遇到第一句句号就丢掉后文的逻辑已移除。没有更换 TTS 引擎/声线；标点影响最终韵律的程度仍取决于本地语音模型。

提示采用“身份、行为、少量风格示例、动态上下文”的结构，参考 [OpenAI 官方提示词指南](https://developers.openai.com/api/docs/guides/prompt-engineering)。示例是虚构风格示意，不是用户历史，也不属于游戏官方台词。未增大最近六条消息的上下文范围。

## 验收

`npm run test:dialogue` 只测试纯函数：设定边界、长度上限、日期注入、第二句保留、停顿、角色名前缀、Unicode、长句截断和真实身份回答不被替换。不能据此保证任何模型一定听从提示。

真实模型试验只向经过本地地址校验的模型客户端发送虚构台词，不调用 API、不打开麦克风、不合成语音、不写入伴侣聊天历史。验收关注：

- 抱怨累：接住情绪，不立刻列解决清单或幼化用户。
- 意见分歧：温和保留判断，不无条件附和，也不刻意抬杠。
- 记忆不确定：承认缺上下文，问一个线索，不补造故事。
- 转写歧义：简短确认意思，不凭错字展开想象。
- 告别：自然结束，不追加问题、挽留或制造亏欠感。
- 身份询问：直接说明是 AI，不用角色名或暧昧情绪绕开问题。

API 或中转服务的实际效果和延迟尚待用户选择服务并主动测试；提示词不是音色克隆、模型训练，也不能消除服务商排队延迟。
