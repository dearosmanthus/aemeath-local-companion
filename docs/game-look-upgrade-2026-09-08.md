# 爱弥斯游戏质感与轻量二次运动 · 2026-09-08

当前前端标记：`game-toon-v4`。用户已手动重启；主程序的首句预合成与语音注意力补丁均已从健康接口确认启用。本轮人物代码已经构建并加载，不需要再次重启后台。

## 这一轮改变了什么

- 按眼、脸、皮肤、头发、金属、衣料分别设置明暗分界和阴影色。脸部法线适度朝头部朝向混合，转头时更新到相机坐标，减少脸上随几何小面跳变的硬影。
- 保留原贴图里的星瞳、粉色头发和浅金发尾；降低球面贴图和高光的泛白。发丝加入沿头部纵向的条带高光近似，衣料保持哑光，金属饰件保留较集中的反射。它不是原游戏的发丝方向贴图方案。
- 蓝色发光饰片与声痕单独保持亮度；没有把整件衣服作为金属或发光材质。新增边缘压暗在现有着色器完成，不是额外的几何描边通道。
- 新增头部局部刘海阴影：只投射“前发”和“后发”两组，512 像素阴影图、最多每秒更新 10 次。投影代理共享原骨骼、索引与顶点缓冲，不复制约 96 MB 的形变纹理。当前 16 个 morph 对投影发片的位移为零；以后资源变化不再满足条件时会停用该代理。
- 阴影约束在头颈区域。原始外观或渲染压力达到第二级时自动关闭并释放阴影图。只增加阴影刷新帧的两次绘制，不增加主画面绘制次数。没有开启 695 个原 PMX 刚体的完整物理系统。
- 跳过原资源里 10 组透明度为零、当前运行时也没有材质 morph 改写的材质。主画面从 44 组 / 176,576 面变为 34 组 / 128,299 面，少绘制 48,277 面，约 27.3%。原网格与贴图文件保留。
- 三组叠在基础头发上的高光发片不再写深度，基础发片继续写深度，减少高光层遮住相邻发片的问题。同一 Mesh 内没有自动逐发片透明排序，不保证任意极端角度完全无穿插。
- 原 18 个发根改为解析阻尼，增加俯仰惯性；补入 3 段经真实骨架验证的中段发链、4 段后方飘带。发梢比发根略迟回落。没有给蒙皮混合复杂的长袖硬加几根摆动骨，以免产生拉裂。
- 修复释放材质后异步贴图失败又改写已恢复材质的问题；修复重复点击“游戏质感”时灯光在阴影更新间隙短暂偏转的问题。

“原始效果”是基础渲染对照档：关闭新增光影，但仍保留隐藏透明组、发片深度等修复，不等于逐项恢复 PMX 原始渲染标志，更不代表游戏引擎原始画面。

## 实际验收

通过 `npm run build:avatar`、`npm run test:avatar`、`npm run check`。测试使用本地真实 PMX 和内存替身，没有发起 AI 对话或外部 API 请求。

- 真实 PMX 的 16 个精选形变、静音闭嘴、肩腕手指、状态切换、30/120 FPS 动作一致性通过。
- 新二次运动抽样 3,303 个蒙皮顶点，额外最大位移 0.174108 模型单位，约站立高度的 1%；发链中段延迟约 67–75 ms。减少动态效果、长时运行及异常 dt 均有测试。
- 阴影测试覆盖真实蒙皮变换、共享资源、脸部裁剪、透明贴图、10 Hz 限频、压力关闭、重复外观切换和释放。Three r185 回调顺序有专门 guard；更新 Three 后需要重新验收。
- 浏览器原生 1280×720 已实看半身、全身、约 24° 侧转、招手的中段与抬手阶段。脚部在全身镜头稳定后留在字幕上方。临时侧转已恢复，最终留在“半身 / 清晰 / 游戏质感”、麦克风关闭的待机界面。
- 最终构建浏览器 error 日志为空。旧 loader 的弃用参数警告仍是已知兼容噪声，不作为已消除项。

### 性能证据与限制

首次新材质加阴影的短时采样为 60.4 FPS、CPU 提交约 1.05 ms、34 次主绘制。阴影刷新帧可读到 36 次 / 149,103 面；额外两次共 20,804 面，其余帧为 34 次 / 128,299 面。

后来采样出现约 8–13 FPS，即使关闭附加阴影、切回基础外观也未恢复稳定 60 FPS；最终 10.6 FPS、CPU 提交约 0.9 ms、自动减负已生效。一次 GPU 快照为 96% 利用率、10,408 / 12,227 MiB 显存、86℃。本轮没有隔离其他程序负载或宿主浏览器调度，因此不能把低帧率全部归因本模型，也不能宣称已解决整机卡顿。CPU 提交时间不是 GPU 完成时间。

声线、参考语料、9B 权重、10 步语音采样均未改变。重启后的固定句复测仍明显慢于实时：3.52 秒音频耗时 13.979 秒；与之前单次 10.849 秒相比没有测出端到端提速。两次冷启动、温度和并行负载不同，不足以把差异归因注意力补丁。详见 [语音复测记录](voice-benchmark-2026-09-08.md)。没有进行真实麦克风全链路听感验收。

## 游戏参照的边界

已定位 [鸣潮官方爱弥斯展示页](https://wutheringwaves.kurogames.com/zh-tw/main/news/detail/4138) 与 [官方战斗演示](https://www.youtube.com/watch?v=VELBYQp7yeY)。本轮成功读取展示页标题、日期及局部截图；网页后续交互多次超时，官方 CDN 图片单独导航返回浏览器阻止，B 站返回 412、YouTube 读取受限。没有绕过这些限制，也没有完成实机视频逐帧观看。

材质调校实际依据本地舞台和原眼、脸、头发贴图。PMX 随附说明明确为二创、实际内容与游戏不同，署名“鸣潮 / 1010浣”。现有资源没有原游戏脸影 SDF、法线和粗糙度贴图。当前结果是保留角色资产并改善实时表现，不能称为完全还原游戏模型。

仍需后续资产工作：官方常态实机近景对照、角色专用脸影遮罩、适配关键帧动作、手部 IK、衣裙碰撞和必要的局部蒙皮修正。本轮没有改变脸部拓扑或用增面替代这些工作。
