# 本地 / API 对话通道

新增于 2026-09-08；按用户“先做通用兼容接口，之后我填写”的选择实现。

## 操作

1. 打开 http://127.0.0.1:17860/stage/，点左上角“对话 · 本地”。
2. 填服务商提供的 HTTPS 接口根地址（通常以 `/v1` 结尾）、模型名和专用于伴侣的 Key。不要将 Key 粘贴进聊天记录。
3. 核对面板展示的完整请求地址，勾选发送范围，点“保存本次配置”。此操作只更新本机内存，不进行试连。
4. 点“使用 API”，再发文字或重新点光核说话。切回本地或点“清除本次 API 配置”均可停止使用 API。

没有预填服务商或模型。根地址不接受 HTTP、直接 IP、URL 内凭据、查询参数、锚点或已包含 `/chat/completions` / `/responses` 的路径。尚不支持 Responses、Realtime、特殊签名认证或供应商专有消息格式。

接口采用 [Chat Completions 官方格式](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)：`POST {baseUrl}/chat/completions`，Bearer 专用 Key，JSON `model/messages/stream:true`。支持 SSE 增量回复，也兼容返回完整 JSON 的服务。是否接受该模型、是否需要其他参数以及实际速度，需用户填写后实际验收；本次没有向真实服务商请求。

## 数据与切换

- 默认本地；配置与 Key 仅保存在后台进程本次运行的内存中。重启后清空，不读取其他应用配置、环境变量中的 Key 或浏览器存储。
- 保存与状态/健康检查不请求 API。只有配置完整、主动选中 API 后的新发言才请求已确认地址。禁止重定向，无自动重试或供应商/本地回退。
- 外发：角色系统设定（含称呼与时间）、当前文字/语音转写、本次 API 会话最近最多 6 条消息。系统设定含本机角色配置，配置中不要放密码等秘密。
- 不外发：音频、人物资源、语音模型、以前的本地聊天。识别、声音、口型仍在本机。
- 成功对话仍按原机制保存到本机历史文件。API 使用独立内存上下文，不读取这个历史文件；切换、清除配置或重启会清空 API 上下文。清空内存不删除已有本机历史。
- 配置变化/切换时：取消生成与播放，暂停麦克风，清空未处理录音及旧排队任务。需重新点光核，避免半句话跨通道发送。
- 多个本机页面共享后台通道，切换会通知所有已连接页面。按钮颜色/标签表示当前通道，不表示已验证服务商可用。
- “清除配置”不是撤回服务商已收到的请求。取消时已到达服务商的请求仍可能产生费用。

## 测试边界

`npm run test:channel` 的目标地址为保留的 `.invalid` 域名，但所有请求均由内存函数替代，不实际联网。服务端处理逻辑在 VM 中执行，HTTP、文件、模型和进程均使用测试替身，不读取真实 Key/历史，也不启动监听。

运行版本标记为 `selectable-chat-v1`，本地组件继续使用 `loopback-only-v2` 限制；这只是兼容性标记，不是加密证明或系统防火墙。
